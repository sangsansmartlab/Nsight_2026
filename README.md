# NSight

> **상산고등학교 SMARTLAB 다차원 뉴스 분석 및 3D 공간 시각화 플랫폼**  
> *Transforming Complex News Streams into an Interactive Multi-Dimensional Knowledge Space*

---

## 1. 프로젝트 개요 (Overview)

**NSight**는 정보 과잉과 여론 양극화 시대에 사용자가 방대한 양의 뉴스를 다차원적 시각에서 입체적으로 이해할 수 있도록 돕는 **실시간 뉴스 인텔리전스 및 3D 공간 시각화 플랫폼**입니다.

기존의 텍스트 나열형 뉴스 서비스와 달리, 사용자가 지정하거나 AI가 제안하는 분석 축(예: 규제 vs 진흥, 사회적 파급력, 정보 신뢰도, 기사 성향 등)을 기반으로 각 기사를 **3D 공간 좌표(X, Y, Z)와 4차원 속성(Color)**에 실시간 배치합니다. 이를 통해 언론사별 시각차, 핵심 쟁점의 분포, 여론의 지형을 한눈에 파악할 수 있습니다.

* **개발:** 상산고등학교 SMARTLAB (김태호, 박민수, 김이현, 차민혁)
* **릴리즈 버전:** 2026 Edition

## 2. 핵심 기능 (Key Features)

### 2.1 실시간 뉴스 수집 & 비동기 스크래핑 엔진
* **대량 기사 메타데이터 검색:** 검색어 및 수집 대상 URL을 기반으로 네이버 뉴스 검색 API 등을 통해 관련 기사 메타데이터(제목, 언론사, 게시일, 원문 링크)를 실시간 수집합니다.
* **고속 비동기 본문 파싱:** 동시성 제어(Semaphore)가 적용된 비동기 워커 풀을 통해 기사 본문을 빠르고 안정적으로 스크래핑하며, 본문 수집 실패 시에도 메타데이터를 보존하여 전체 파이프라인의 중단을 방지합니다.

### 2.2 4차원 좌표계 매핑 & AI Rationale
* **다차원 벡터 좌표화:** 각 기사는 3개 공간 축($X, Y, Z \in [-1.0, 1.0]$)과 1개 색상 축(4D Color Label & Hex)으로 정량화됩니다.
  * **X축:** 쟁점 대립각 (예: 산업 진흥 vs 규제 강화)
  * **Y축:** 파급력 및 사회적 영향도
  * **Z축:** 정보 신뢰도 및 근거 완성도
  * **Color:** 기사 성향 (긍정/부정/중립/건설적 등)
* **AI 정성 분석(Rationale):** 수치화된 좌표뿐만 아니라, AI가 해당 좌표를 산출한 논리적 근거(AI Rationale)와 핵심 키워드를 함께 제공합니다.
* **3줄 핵심 요약:** 긴 기사 원문을 핵심 논점 위주의 3줄 요약(`summary_3lines`)으로 압축하여 전달합니다.

### 2.3 인터랙티브 3D 공간 시각화 & 2D-3D 양방향 동기화
* **Three.js & React Three Fiber (R3F):** 수십~수백 개의 기사 노드를 GPU 인스턴싱(`InstancedMesh`)을 통해 60fps로 매끄럽게 렌더링합니다.
* **양방향 인터랙션:**
  * **Hover / Tap:** 3D 공간 상의 기사 노드에 마우스를 올리거나 터치하면 언론사명, 제목, 3줄 요약 툴팁이 즉시 노출됩니다.
  * **Click / Double Tap:** 기사 노드를 선택하면 카메라가 해당 위치로 부드럽게 이동(Camera Lerp)하며, 우측 상세 정보 패널(Detail Drawer)이 열려 기사 전문 및 AI 분석 결과를 확인할 수 있습니다.
  * **스케일 조절 & 공간 확대:** 노드 밀집 영역을 해소하기 위해 실시간 좌표 스케일 팩터 슬라이더를 지원합니다.
  * **모바일 최적화:** 핀치 줌(Pinch-to-Zoom), 한 손가락 회전 등 모바일 터치 제스처를 완벽하게 지원합니다.

### 2.4 지능형 다중 LLM Fallback 파이프라인
* **초고속 병렬 배치 처리:** 기사들을 단위 청크(Chunk)로 묶어 고속 추론 엔진으로 병렬 분석합니다.
* **무중단 다계층 Fallback:** 1차 모델 지연/오류 시 2차, 3차 모델로 자동 전환되어 서비스 연속성을 보장합니다.
* **엄격한 스키마 검증:** Pydantic / TypeScript 인터페이스 기반의 엄격한 JSON 유효성 검증과 지수 백오프(Exponential Backoff) 재시도 로직을 통해 결측 데이터를 사전에 차단합니다.

### 2.5 사용자 편의 및 결과 공유
* **3D 스냅샷 저장:** 분석된 3D 지도를 고유 식별자와 함께 저장하고 언제든 다시 불러올 수 있습니다.
* **공유 및 내보내기:** 3D Canvas 고화질 이미지(PNG) 캡처, 분석 데이터(CSV, JSON) 다운로드 및 고유 URL 공유 기능을 제공합니다.
* **시연용 캐시 모드:** 주요 사회적 이슈(예: AI 기본법 등)에 대한 사전 분석 캐시를 내장하여 즉각적인 시각화 데모가 가능합니다.

## 3. 권한 체계 (Role-Based Access Control)

| 사용자 구분 | 접근 권한 및 제공 기능 |
| :--- | :--- |
| **비회원 (Guest)** | • 검색 키워드 및 수집 수량(10~100개) 설정<br>• 3D 시각화 조작 및 4D 컬러 분석 확인<br>• 노드 인터랙션(Hover 툴팁, 상세 패널 확인)<br>• 커스텀 분석 축 설정 및 실시간 재분석 |
| **인증 회원 (Verified User)** | • Guest의 모든 기본 기능<br>• 분석 3D 지도 스냅샷(Snapshot) 저장 및 불러오기<br>• 검색 히스토리 타임라인 조회 및 관리<br>• 고유 공유 링크 생성 및 내보내기 |
| **관리자 (Admin)** | • 플랫폼 전체 이용 현황 통계<br>• API 사용량 모니터링 및 캐시 관리 |

## 5. 시스템 파이프라인 흐름

```
[ 사용자 검색 요청 (Query, Custom Axes) ]
                   │
                   ▼
       [ 1단계: 뉴스 메타데이터 수집 ]
         - 네이버 뉴스 검색 API 호출
         - 10~100개 기사 메타데이터(제목, 언론사, 링크) 확보
                   │
                   ▼
       [ 2단계: 비동기 기사 본문 스크래퍼 ]
         - 동시성 제어 기반 비동기 스크래핑
         - 본문 텍스트 정제 및 길이 정규화
                   │
                   ▼
       [ 3단계: 다중 LLM 분석 오케스트레이터 ]
         - 10개 단위 청크 병렬 처리
         - 3줄 요약, 키워드 추출, 다차원 좌표 및 근거 도출
         - 다계층 Fallback 및 지수 백오프 검증
                   │
                   ▼
       [ 4단계: 좌표 정규화 & 시각화 동기화 ]
         - 공간 중첩 방지 가우시안 노이즈(±0.01) 보정
         - 4D 컬러 라벨 매핑
                   │
                   ▼
[ React Three Fiber 3D 공간 렌더링 & 2D 인터랙션 패널 ]
```

## 7. 프로젝트 규범 및 개발 원칙

본 프로젝트의 아키텍처 규칙, 도메인 가치, AI 모델 간 협업 원칙은 저장소 내 `PROJECT_RULES.md`에 정의되어 있습니다. 본 프로젝트를 수정하거나 확장하는 모든 개발자 및 AI 어시스턴트는 해당 규범을 숙지하고 따라야 합니다.
