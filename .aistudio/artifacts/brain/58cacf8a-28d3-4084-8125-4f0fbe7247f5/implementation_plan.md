# NSight 3D — 코드 충돌 해결 및 누적 기능 완전 통합 계획서

코드 점검에서 발견된 **4건의 컴파일·런타임 충돌 및 API 불일치 버그를 모두 해결**하고, 첫 랜딩 화면(`LANDING`)을 유지하면서 지금까지 확정한 모든 기능(**1·2·3순위 축 설정, 개인 경향성 기반 최상단 검색 노출, 검색 시 양옆 패널 자동 접힘 및 수동 토글, 3D 좌표평면 내 기사별 경향성 시각화, 부드러운 카메라 포커스 이동**)을 충돌 없이 하나로 통합합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 코드 점검을 통해 확인된 충돌 해결 방안과 기존 확정 요구사항을 모두 통합한 결정 사항입니다.

- **확정 결정 1 (발견된 코드 충돌 및 런타임 버그 4건 완전 수정)**:
  1. **검색·축 설정 모달 크래시 해결**: 미선언 식별자(`AXIS_PRESET_TEMPLATES`, `setIsAutoAxesEnabled`) 참조를 제거하고, **1·2·3순위 좌표축 및 개인 경향성 설정 상태**와 정합성 있게 연결합니다.
  2. **3D 씬 재생성 및 카메라 위치 초기화 버그 해결**: 노드를 클릭하거나 호버할 때마다 Three.js WebGL 씬이 초기화되던 의존성 충돌을 분리하여, 씬을 유지한 채 **선택·검색 매칭 노드로 카메라가 부드럽게 보간 이동(Cubic Ease-Out Lerp)**하도록 수정합니다.
  3. **관리자 대시보드 Groq 5-Key Pool 상태 연동 수정**: 백엔드 `/api/v1/groq/status` 응답 스키마(`slots`, `id`, `isConfigured`, `requestCount`, `rateLimitCount`, `isCoolingDown`)와 프론트엔드 대시보드 렌더링 필드를 일치시킵니다.
  4. **3D 탐색 화면 모달·공유·내보내기 연결 및 크롤러 타입 오류 수정**: 탐색 화면에서도 스냅샷 드로어, 관리자 모달, RBAC 가드, CSV/JSON/PNG 내보내기 및 기사 공유가 모두 동작하도록 연결하고, 백엔드 크롤러의 비표준 문자열 메서드 참조를 표준 TypeScript로 수정합니다.
- **확정 결정 2 (첫 랜딩 화면 유지 + 1·2·3순위 축 및 개인 경향성 설정 통합)**:
  - 앱 시작 시 **랜딩 화면(`LANDING`)을 그대로 유지**하며, 랜딩 화면의 설정 패널과 3D 탐색 화면 상단의 `[내 기준 · 1·2·3순위 축 설정]`에서 언제든 **1순위(X축)·2순위(Y축)·3순위(Z축) 기준 작성 및 순서 변경(`↑/↓`)**과 **개인 선호 경향성(선호 방향, 성향, 관심 키워드)**을 설정할 수 있도록 지원합니다.
- **확정 결정 3 (누적 확정 기능 전체 보존 및 통합)**:
  - **상단 헤더 아래 중앙 독립형 검색 바 & 실시간 드롭다운**: 화면 크기에 관계없이 가려지지 않는 중앙 검색 바와 `#키워드` 추천 필터 및 기사 목록 드롭다운을 제공합니다.
  - **개인 경향성 + 1·2·3순위 축 가중치(50% / 30% / 20%) 기반 최상단 정렬**: 사용자의 기준과 가장 잘 부합하는 기사가 검색 결과 가장 위에 `★ 맞춤 1위 (일치도 %)`와 함께 표시됩니다.
  - **양옆 좌·우 패널 접기/펼치기 및 검색 시 자동 접힘(Auto-Collapse)**: 좌측 패널과 우측 상세 패널 모두 접었다 펼칠 수 있는 토글 버튼을 제공하고, **검색창을 클릭하거나 검색할 때는 양옆 패널이 자동으로 접혀** 시야를 가리지 않게 합니다.
  - **3D 좌표평면 내 기사별 경향성 시각화**: 각 구체 노드 상단에 기사의 경향성과 1순위 축 점수를 보여주는 3D 플로팅 배지 및 원점 `(0,0,0)` 발사 경향성 벡터선을 표시합니다.

## 1. Overview & Core Concept

- **What It Does**:
  1. **랜딩 화면 & 개인화 기준 설정**: 첫 화면에서 검색어를 입력하거나, 1순위·2순위·3순위 좌표축(예: `1순위: 수익성`, `2순위: 연관성`, `3순위: 미래 지향성`)과 개인 경향성 기준을 설정하고 실시간 3D 분석을 시작합니다.
  2. **독립형 중앙 검색 바 & 양옆 패널 자동 접힘**: 3D 탐색 화면 상단 헤더 바로 아래 중앙에 위치한 검색창을 클릭하거나 타이핑하면, 좌·우측 패널이 자동으로 접히고 개인 맞춤 점수순으로 정렬된 실시간 드롭다운 목록이 열립니다.
  3. **3D 좌표평면 경향성 표시 & 부드러운 카메라 이동**: 3D 공간의 X·Y·Z 축이 `[1순위]`, `[2순위]`, `[3순위]` 순서로 표시되며, 각 기사 노드 위에 경향성 배지가 함께 렌더링되고 검색 매칭 1위 노드 또는 클릭한 노드로 카메라가 끊김 없이 부드럽게 이동합니다.
- **Target Audience / Persona**: 자신이 중요하게 생각하는 기준의 우선순위(1·2·3순위)와 경향성에 맞춰 최신 뉴스를 실시간 검색하고, 깔끔한 3D 공간에서 기사별 경향성을 한눈에 비교하려는 사용자.
- **Key Value**: 런타임 크래시와 상태 충돌이 없는 안정적인 코드 구조 위에서, 검색 엔진으로서의 실시간 뉴스 수집, 개인 맞춤형 최상단 추천, 접이식 HUD, 3D 입체 경향성 시각화를 매끄럽게 제공합니다.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **첫 랜딩 화면 (`LANDING` 모드)**:
     - 중앙 검색창과 추천 키워드 칩, 그리고 `[검색 및 1·2·3순위 축 · 내 경향성 설정]` 패널을 제공합니다.
     - 사용자는 분야별 프리셋(경제·기업: `1순위 수익성 / 2순위 연관성 / 3순위 미래 지향성`, AI·정책: `1순위 산업 진흥성 / 2순위 사회적 파급력 / 3순위 정보 신뢰도` 등)을 고르거나 직접 1·2·3순위 축 이름·양극단 설명을 입력하고 `↑ / ↓` 버튼으로 순위를 바꿀 수 있습니다.
     - 각 축의 선호 방향(양(+) 선호 / 균형 / 음(-) 선호)과 선호 성향(`전체`, `긍정/지지`, `중립/건설적`, `우려/비판`), 관심 키워드를 설정할 수 있습니다.
  2. **3D 탐색 화면 (`EXPLORER` 모드) — 헤더 및 중앙 독립형 검색 바**:
     - 상단 헤더에는 홈(랜딩 이동) 로고, 시점 프리셋(`3D 입체`, `정면 XY`, `평면 XZ`, `측면 YZ`), 이슈 스위처, `[내 기준 · 축 순위 설정]`, `[스냅샷·히스토리]`, `[내보내기/공유]`, `[로그인/계정]` 버튼이 배치됩니다.
     - 상단 헤더 바로 아래 중앙에는 **독립된 플로팅 검색 바**가 고정 배치되어 작은 화면에서도 절대 가려지지 않습니다.
     - 검색창에 포커스하거나 검색어를 입력하면 **좌측 패널과 우측 패널이 자동으로 접히며(Auto-Collapse)**, 검색바 아래로 `#키워드` 빠른 필터와 **개인 맞춤 점수(`personalScore`) 내림차순으로 정렬된 기사 드롭다운 목록**이 펼쳐집니다.
  3. **3D 좌표평면 내 기사별 경향성 시각화 & 카메라 포커스**:
     - 세 공간 축 끝단에는 `[1순위 · X축]`, `[2순위 · Y축]`, `[3순위 · Z축]` 라벨 배지가 표시되며 카메라 줌인 시 Dynamic Fade가 동작합니다.
     - 각 기사 구체(Sphere) 위에는 **기사 경향성 및 1순위 축 점수 배지**와 **원점 `(0,0,0)` 기준 경향성 벡터선**이 표시됩니다(좌측 패널에서 표시 여부 ON/OFF 가능).
     - 드롭다운에서 기사를 클릭하거나 3D 노드를 클릭하면 WebGL 씬이 초기화되지 않고 **카메라가 해당 노드로 부드럽게 이동(Lerp)**하며, 우측 상세 패널이 자동으로 펼쳐집니다.
  4. **양옆 패널 수동 접기/펼치기 토글**:
     - 화면 좌측 가장자리와 우측 가장자리에 각각 접기/펼치기 토글 탭(`[◀ 1·2·3순위 축 & 공간 제어]`, `[기사 상세 분석 ▶]`)이 상시 제공되어 사용자가 원할 때 언제든 개별 패널을 열거나 접을 수 있습니다.

- **Visual Identity & Theme**:
  - *Aesthetic Direction*: 다크 슬레이트(`#0b0f19`) 배경의 정밀 3D 인텔리전스 HUD.
  - *Color Palette & Mood*:
    - **1순위 축 (X축)**: 로즈 레드 (`#F43F5E`)
    - **2순위 축 (Y축)**: 에메랄드 그린 (`#10B981`)
    - **3순위 축 (Z축)**: 로얄 퍼플 (`#A855F7`)
    - **4차원 연속 색상 (Color축)**: 수치 크기와 부호에 비례하는 연속 스펙트럼 그라데이션 (원점 `0.0` 순백색 기준)
    - **맞춤 1위 & 선택 포커스**: 앰버 골드 (`#F59E0B`) 및 스카이 블루 (`#38BDF8`)
  - *Typography & Hierarchy*: `Pretendard` 본문 폰트와 `font-mono tabular-nums` 수치 정렬.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: WebGL 씬 생성 라이프사이클과 선택/호버/카메라 상태 분리**
  - *Chosen Approach*: Three.js 씬·렌더러·카메라 초기화 이펙트와 노드 선택·호버 하이라이트·카메라 Lerp 이동 이펙트를 분리하여, 노드를 클릭하거나 검색 결과를 선택해도 씬이 파괴되지 않고 부드럽게 카메라가 이동하도록 설계합니다.
  - *Why*: 기존 코드에서 노드를 클릭할 때마다 카메라가 초기 위치로 리셋되던 문제를 근본적으로 해결하고 60fps 렌더링 성능을 보장합니다.
- **Decision 2: 1·2·3순위 축(`RankedAxisItem`)과 `CustomAxes`의 양방향 동기화**
  - *Chosen Approach*: 사용자가 설정한 1순위·2순위·3순위 축 배열(`rankedAxes`)이 변경될 때마다 1순위→`x_axis`, 2순위→`y_axis`, 3순위→`z_axis`로 자동 동기화하며, 순위 맞바꾸기(`↑/↓`) 시 기존 기사들의 $(X, Y, Z)$ 좌표값도 해당 순위 축에 맞춰 즉시 스왑합니다.
  - *Why*: 재검색 없이도 순위 변경 즉시 3D 좌표평면의 노드 배치와 개인 맞춤 점수가 실시간으로 반영됩니다.
- **Decision 3: 백엔드 API 응답과 프론트엔드 대시보드 스키마 통일**
  - *Chosen Approach*: `/api/v1/groq/status` 응답과 관리자 모달의 슬롯 상태 인터페이스를 단일 표준으로 맞춰 5개 Groq API 키 슬롯의 가용 여부, 요청 횟수, Rate Limit 쿨다운 상태를 정확히 표시합니다.
  - *Why*: 미정의 필드 참조로 인한 무한 로딩 현상을 제거합니다.

- **Data Model & State**:
  - `rankedAxes`: `[RankedAxisItem, RankedAxisItem, RankedAxisItem]` — 1순위(X축, 가중치 50%), 2순위(Y축, 가중치 30%), 3순위(Z축, 가중치 20%) 축의 이름, 양/음 극단 설명, 선호 방향(`1 | 0 | -1`)을 관리합니다.
  - `userPreference`: `{ preferredSentiment, interestKeywords }` — 사용자의 선호 성향 및 관심 키워드를 저장합니다.
  - `scoredArticles`: 필터링된 각 기사에 대해 1·2·3순위 축 적합도(50/30/20%) + 선호 성향 일치도 + 관심 키워드 매칭도를 합산하여 `personalScore (0~100)`를 산출하고 내림차순 정렬합니다.
  - `isLeftPanelOpen` / `isRightPanelOpen`: 좌·우 패널의 개별 접힘/펼침 상태를 관리하며, 검색창 포커스/입력 시 두 상태를 모두 `false`로 전환합니다.
  - `show3DTendency`: 3D 좌표평면 위 각 노드의 경향성 배지 및 원점 발사 벡터선 표시 여부를 제어합니다.
- **Interactive Component & State Mapping**:
  - **1·2·3순위 축 순서 변경 핸들러**: 사용자가 `↑` 또는 `↓` 버튼을 누르면 두 순위 축의 설정을 교환하고, 현재 로드된 기사들의 해당 좌표축 값(`x`, `y`, `z`)도 함께 교환하여 3D 공간 배치가 즉시 업데이트됩니다.
  - **검색 포커스 및 입력 핸들러**: 검색창 클릭/타이핑 시 `isLeftPanelOpen = false`, `isRightPanelOpen = false`, `isSearchDropdownOpen = true`로 전환하고, 매칭된 1위 기사로 3D 카메라 타겟을 부드럽게 이동시킵니다.
  - **드롭다운 항목 / 3D 노드 선택 핸들러**: 해당 기사를 `selectedArticle`로 지정하고, 카메라를 해당 노드 좌표로 부드럽게 Lerp 이동시키며, `isRightPanelOpen = true`로 우측 분석 패널을 펼칩니다.
