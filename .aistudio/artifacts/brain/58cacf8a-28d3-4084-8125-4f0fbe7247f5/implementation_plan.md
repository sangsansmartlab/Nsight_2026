# NSight 3D — 찾은 기사 3D 좌표 공간 실시간 추가·병합(Add & Merge to 3D Space) 계획서

기존에 구현된 **1·2·3순위 축 및 가중치 설정**, **개인 기사 평가 및 적응형 3D 좌표축 진화**, **인앱 뉴스 리더 모달 및 4대 뉴스 매개체(네이버·구글·다음·언론사) 연동**을 모두 유지하면서, **사용자가 찾은 기사를 현재 보고 있는 3D 좌표 공간에 새로운 점(노드)으로 즉시 분석·추가하고 해당 점으로 3D 카메라를 포커스하는 3종 추가 시스템**을 구축합니다.

---

## 1. 핵심 사용자 경험(UX) 및 3가지 기사 추가 경로 설계

### ① 인앱 뉴스 리더 모달 내 ‘관련 실시간 뉴스’ 원클릭 3D 좌표 추가
- 인앱 뉴스 리더 모달(`ArticleReaderModal`) 하단의 **「관련 실시간 뉴스 매개체 보도」** 목록에 있는 각 기사 우측에 **「+ 현재 3D 좌표에 추가」** 버튼을 배치합니다.
- 사용자가 관련 뉴스를 읽다가 원하는 기사의 **「+ 현재 3D 좌표에 추가」** 버튼을 클릭하면:
  1. 백엔드 단일 기사 분석 파이프라인(`POST /api/v1/add-article`)이 현재 설정된 **1·2·3순위 축(`rankedAxes`)** 기준으로 해당 기사의 3D 좌표 `(x, y, z)`, 4D 성향 색상, 핵심 3줄 요약, 산출 근거를 실시간 산출합니다.
  2. 현재 열려 있는 3D 좌표 공간(`dataset.articles`)에 중복 없이 새로운 구체(점)로 즉시 추가됩니다.
  3. 이미 3D 공간에 추가된 기사는 **`✓ 좌표에 추가됨 (점 보기)`** 버튼으로 상태가 바뀌며, 클릭 시 즉시 해당 점으로 3D 카메라가 이동합니다.

---

### ② 외부 기사(네이버·구글·다음 뉴스 URL 또는 제목·본문) 직접 3D 좌표 추가 모달 (`+ 기사 직접 추가`)
- 상단 검색바 우측 및 좌측 패널에 **「+ 외부 기사 3D 추가」** 버튼을 배치합니다.
- 클릭 시 열리는 **「외부 뉴스 기사 3D 좌표 추가 모달」**에서 두 가지 입력 방식을 모두 지원합니다:
  1. **기사 링크(URL)로 자동 추출·추가**: 네이버 뉴스, 다음 뉴스, 또는 언론사 기사 URL을 붙여넣으면 백엔드 크롤러가 제목·언론사·본문을 자동 추출한 뒤 현재 1·2·3순위 축 기준의 3D 좌표를 산출하여 점으로 추가합니다.
  2. **기사 제목 / 키워드 / 요약문으로 검색·추가**: 외부 포털에서 본 기사 제목이나 핵심 문장을 입력하면 실시간 뉴스 검색 또는 직접 분석을 통해 현재 3D 좌표 공간에 즉시 새로운 점으로 추가합니다.

---

### ③ 상단 검색창 ‘기존 3D 좌표에 누적 추가’ vs ‘새 공간으로 탐색’ 지원
- 상단 검색바 및 검색 드롭다운에서 새로운 키워드로 실시간 뉴스를 찾을 때 두 가지 실행 옵션을 모두 제공합니다:
  1. **`실시간 새로 탐색` (기존 방식)**: 검색된 기사들로 새로운 3D 좌표 공간을 생성합니다.
  2. **`+ 현재 좌표에 누적 추가` (신규 병합 방식)**: 현재 보고 있는 3D 좌표 공간의 기존 점들을 그대로 유지한 채, 새로 검색된 기사들을 현재 1·2·3순위 축 기준으로 분석하여 **기존 3D 공간에 함께 병합(Merge)**합니다. (중복 기사는 자동 제거)

---

### ④ 신규 추가된 점(노드) 3D 카메라 즉시 포커스 & `NEW` 배지 시각화
- 새로운 기사가 3D 좌표 공간에 추가되는 즉시:
  1. **3D 카메라 자동 포커스 및 선택(눌러진 상태) 활성화**: 방금 추가된 기사가 자동으로 선택(`selectedArticle`)되어 3D 카메라가 해당 구체로 부드럽게 이동(Lerp)하고, X·Y·Z 3D 좌표 튜브와 우측 상세 분석 패널이 즉시 열립니다.
  2. **`NEW 신규 추가` 배지 및 3D 강조 링 표시**: 새로 추가된 기사들은(`addedArticleIds`) 검색 드롭다운과 우측 상세 패널에 **`NEW 신규 추가`** 배지가 부착되고, 3D 공간에서도 선명한 강조 링으로 한눈에 식별할 수 있습니다.

---

## 2. 데이터 흐름 및 아키텍처 다이어그램

```
[사용자가 기사를 찾는 3가지 경로]
  ├─ 경로 1: 인앱 리더 모달 내 '관련 실시간 뉴스' ──► [+ 3D 좌표에 추가] 원클릭
  ├─ 경로 2: 상단 [+ 외부 기사 추가] 모달 ─────────► 네이버·언론사 URL 또는 제목·본문 입력
  └─ 경로 3: 상단 검색바 [+ 현재 좌표에 누적 추가] ─► 검색된 기사 묶음 병합 요청
          │
          ▼
[Express 백엔드 분석 & 추출 파이프라인]
  ├─ POST /api/v1/add-article : URL 메타데이터·본문 크롤링 + 현재 1·2·3순위 축 기준 4D 좌표 산출
  └─ POST /api/v1/search      : 다건 실시간 뉴스 수집 + 현재 1·2·3순위 축 기준 4D 좌표 산출
          │
          ▼
[현재 3D 좌표 공간(dataset.articles) 실시간 병합 & 포커스]
  ├─ 중복 기사 자동 필터링 후 현재 dataset.articles에 신규 노드 추가
  ├─ addedArticleIds에 등록하여 [NEW 신규 추가] 배지 부여
  └─ 방금 추가된 노드를 자동 선택(Pressed)하여 3D 카메라 부드러운 이동 & 우측 상세 패널 오픈
```

---

## 3. 단계별 구현 및 검증 계획

1. **백엔드 단일 기사 URL/제목 크롤링 및 3D 좌표 산출 API 구축 (`POST /api/v1/add-article`)**:
   - `server/services/crawlerService.ts`에 외부 기사 URL에서 제목·언론사·본문을 추출하는 `extractArticleFromUrl` 메서드를 추가합니다.
   - `server/routes/api.ts`에 `POST /api/v1/add-article` 엔드포인트를 추가하여 URL 또는 제목·본문 입력 시 현재 `custom_axes` 및 `ranked_axes` 기준으로 분석된 `Article` 객체를 반환하도록 구현합니다.
2. **인앱 리더 모달(`ArticleReaderModal.tsx`) 내 연관 뉴스 원클릭 3D 추가 기능 연결**:
   - 연관 실시간 뉴스 각 항목에 **「+ 3D 좌표에 추가」** 버튼(로딩 스피너 및 추가 완료 시 **「✓ 추가됨 · 점 보기」** 상태 전환 포함)을 구현합니다.
3. **외부 기사 직접 추가 모달 및 상단 검색바 ‘누적 추가(Merge)’ 기능 구현 (`App.tsx`)**:
   - 상단 바에 **「+ 기사 추가」** 버튼과 외부 기사 URL/제목 입력 모달을 추가합니다.
   - 상단 검색바와 드롭다운에 **「+ 현재 좌표에 누적 추가」** 버튼을 추가하여 기존 3D 공간에 새 검색 기사들을 합칠 수 있게 합니다.
   - 기사 추가 시 `addedArticleIds`에 기록하고, 추가된 노드로 3D 카메라 포커스 및 우측 상세 패널이 즉시 열리도록 연결합니다.
4. **린트 및 빌드 무결성 검증**:
   - `lint_applet` 및 `compile_applet`을 실행하고 개발 서버를 재시작하여 전체 동작을 검증합니다.
