# NSight 3D — 모드별 독립 3D 그래프 공간(뉴스·쇼핑·논문·특허·통계·지식·심층) 전환 및 전용 기사 수집 시스템

모든 종류의 기사가 한 그래프에 뒤섞여 재배열되는 방식이 아니라, **7가지 모드(`뉴스 모드`, `쇼핑 모드`, `논문 모드`, `특허 모드`, `통계 모드`, `지식 모드`, `심층 모드`) 각각이 고유한 X·Y·Z·색상 축과 전용 기사들로만 구성된 독립된 3D 그래프 공간**을 가지며, 모드 칩 버튼을 누르면 **해당 모드의 전용 3D 그래프로 즉시 이동**하여 그 모드에 속한 기사들만 모여 있는 공간을 보여줍니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 피드백을 반영하여 **"하나의 섞인 그래프에서 필터링/재배열"** 하는 방식을 폐기하고, **"모드 칩 클릭 시 해당 모드 전용 기사들만 모여 있는 독립 3D 그래프로 이동"** 하도록 아키텍처를 전면 수정했습니다.

- **Confirmed Decision 1 — 모드별 독립 3D 그래프(Dedicated Mode Graph) 분리**:
  - `전체 섞기` 탭을 두지 않고, 사용자가 선택한 단일 모드(예: `논문 모드`, `특허 모드`, `쇼핑 모드` 등)의 기사들만 온전히 모여 있는 **모드 전용 3D 그래프 공간**이 각각 독립적으로 존재합니다.
  - 검색창 근처의 모드 칩 버튼을 클릭하면 기존 그래프의 점들을 단순히 재배열하는 것이 아니라, **선택한 모드의 고유 축(`X축 · Y축 · Z축 · 색상`)과 해당 모드로 수집·분류된 전용 기사들로 이루어진 3D 그래프로 이동**합니다.
- **Confirmed Decision 2 — 7대 모드별 전용 그래프 축 및 수집 규격**:
  1. **뉴스 모드 그래프** (`사안·이슈·최신 소식 보기`): X축 `반대 ↔ 찬성` · Y축 `파급력` · Z축 `신뢰도` · 색상 `논조` (시사·언론 보도 기사들로만 구성)
  2. **쇼핑 모드 그래프** (`제품 비교하고 고르기`): X축 `저가 ↔ 고가` · Y축 `품질·성능` · Z축 `후기 신뢰도` · 색상 `가성비` (제품 리뷰·비교·가격 분석 기사들로만 구성)
  3. **논문 모드 그래프** (`학술 근거 찾기`): X축 `이론 ↔ 응용` · Y축 `근거 강도` · Z축 `최신성` · 색상 `분야` (학술 연구·논문·실험 결과 기사 및 자료들로만 구성)
  4. **특허 모드 그래프** (`기술·아이디어 선행 조사 (KIPRIS)`): X축 `기초 ↔ 응용` · Y축 `권리 범위` · Z축 `최신성` · 색상 `출원인 유형` (특허 출원·핵심 기술·KIPRIS 선행기술 관련 기사들로만 구성)
  5. **통계 모드 그래프** (`공공데이터·수치 근거 찾기`): X축 `영향 범위` · Y축 `데이터 신뢰도` · Z축 `최신성` · 색상 `기관 유형` (공공 통계·지표·수치 보고서 기반 기사들로만 구성)
  6. **지식 모드 그래프** (`개념·원리 이해하기`): X축 `쉬움 ↔ 전문적` · Y축 `핵심도` · Z축 `정확도` · 색상 `자료 유형` (개념 해설·배경 원리·가이드 성격의 기사들로만 구성)
  7. **심층 모드 그래프** (`복합 주제 깊게 조사하기`): X축 `AI가 정함` · Y축 `AI가 정함` · Z축 `신뢰도` · 색상 `하위 질문` (주제에 대해 AI가 설정한 핵심 쟁점 축과 하위 질문별 심층 분석 기사들로만 구성)

## 1. Overview & Core Concept

- **What It Does**:
  - 각 모드는 서로 다른 목적과 좌표계를 가진 **별개의 3D 공간(독립 그래프)** 입니다.
  - 사용자가 검색창 근처의 모드 버튼(`뉴스 모드`, `쇼핑 모드`, `논문 모드`, `특허 모드`, `통계 모드`, `지식 모드`, `심층 모드`)을 누르면, 화면이 **그 모드의 3D 그래프로 전환**되며 해당 모드의 기준에 맞춰 구해진 전용 기사들만 3D 공간과 좌·우측 패널에 표시됩니다.
  - 동일한 검색어(예: `AI 기본법` 또는 사용자 검색 키워드)에 대해서도 각 모드별로 전용 데이터셋(`modeGraphs[modeId]`)을 독립적으로 구하고 보관하므로, 다른 모드 버튼을 누를 때마다 그 모드만의 전용 기사들이 모인 3D 그래프로 즉시 이동할 수 있습니다.
- **Target Audience / Persona**:
  - 하나의 주제에 대해 뉴스 여론, 제품/쇼핑 비교, 학술 논문 근거, 특허 선행 조사, 통계 수치, 기초/전문 지식, 심층 다각도 조사를 각각 별도의 전용 3D 공간에서 명확히 구분하여 탐색하고자 하는 사용자.
- **Key Value**:
  - 성격이 다른 기사들이 한 공간에 섞이지 않고, 선택한 모드의 목적에 부합하는 기사들만 전용 3D 좌표계에 모여 있어 직관적이고 정확한 공간 탐색이 가능합니다.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **모드 칩 버튼 클릭 → 해당 모드의 전용 3D 그래프로 즉시 이동**:
     - 랜딩 화면 검색창 주변 및 3D 탐색 화면 상단 검색창 바로 아래에 7개 모드 칩 버튼(`뉴스 모드`, `쇼핑 모드`, `논문 모드`, `특허 모드`, `통계 모드`, `지식 모드`, `심층 모드`)이 배치됩니다.
     - 사용자가 특정 모드 버튼(예: `특허 모드`)을 누르면:
       - 3D 캔버스가 **`특허 모드` 전용 그래프 공간**(`X: 기초 ↔ 응용`, `Y: 권리 범위`, `Z: 최신성`, `색상: 출원인 유형`)으로 즉시 전환됩니다.
       - 해당 모드 그래프에는 오직 **특허·기술 선행 조사 성격의 기사들만** 모여 있으며, 카메라가 그 모드 그래프의 1위 노드로 부드럽게 이동합니다.
       - 만약 현재 검색어에 대해 해당 모드의 기사가 아직 수집되지 않았다면, 서버에서 해당 모드 전용 쿼리로 기사들을 새로 구해와 그 모드의 전용 3D 그래프를 생성합니다.
  2. **모드 목록 가이드 표 (참조 이미지 규격)**:
     - 검색창 옆 `모드 목록` 버튼을 통해 7대 모드의 `이럴 때 쓰세요 | X축 | Y축 | Z축 | 색상` 안내 표를 확인할 수 있으며, 표에서 원하는 모드를 클릭해도 즉시 그 모드의 3D 그래프로 이동합니다.
  3. **모드별 독립 그래프 상태 유지**:
     - 각 모드 그래프에서 수행한 기사 선택, 축 가중치 조절, 기사 추가 결과는 해당 모드 그래프(`modeDatasets[activeMode]`)에 독립적으로 유지되어, 다른 모드로 이동했다가 돌아와도 그 모드의 그래프가 그대로 보존됩니다.
- **Visual Identity & Theme**:
  - *Aesthetic Direction*: Deep Obsidian 3D Spatial HUD (`#0B0F19` / `slate-950`) 기반 다크 글래스모피즘.
  - *Color Palette & Mood*:
    - 현재 어느 모드의 그래프에 와 있는지 한눈에 알 수 있도록 각 모드 그래프마다 고유 테마 배지(뉴스-블루, 쇼핑-에메랄드, 논문-인디고, 특허-앰버, 통계-시안, 지식-바이올렛, 심층-로즈)와 전용 4D 색상 범례를 표시합니다.
  - *Typography & Hierarchy*:
    - `Pretendard` 본문·헤드라인 + 좌표/수치용 `font-mono tabular-nums`.
- **Interactive Feedback & Motion**:
  - 모드 버튼 클릭 시 3D 공간 상단에 현재 진입한 모드 그래프 이름과 용도(`예: [특허 모드 그래프] 기술·아이디어 선행 조사 (KIPRIS)`)가 명확히 표시되며, 3D 카메라가 해당 모드 그래프의 중심/최상위 기사로 포커싱됩니다.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1 — 단일 혼합 그래프 배제 & 7개 모드별 전용 그래프 스토어(`Record<ModeId, DatasetItem>`) 운영**:
  - *Chosen Approach*: 애플리케이션 상태를 단일 `dataset`이 아니라 7개 모드 각각의 전용 그래프 맵(`modeDatasets: Record<SearchModeId, DatasetItem>`)으로 관리합니다.
  - *Why*: 버튼을 누를 때 기존 기사를 억지로 재배열하지 않고, 각 모드에 맞는 전용 기사들만 모여 있는 별도의 3D 그래프로 즉시 이동(`Switch Graph`)하기 위함입니다.
- **Decision 2 — 모드별 전용 기사 수집(Domain-Specific Crawling & Analysis)**:
  - *Chosen Approach*: 백엔드 `/api/v1/search`에 `mode` 파라미터를 전달하여, 모드별로 수집 쿼리와 필터링 기준을 분리합니다(예: `쇼핑 모드`는 제품 비교·가격·성능·후기 기사만 수집, `논문 모드`는 학술·연구·논문 기사만 수집, `특허 모드`는 특허·출원·기술 기사만 수집, `통계 모드`는 통계·수치·공공데이터 기사만 수집, `지식 모드`는 개념·원리·해설 기사만 수집, `심층 모드`는 AI가 도출한 쟁점 축과 하위 질문별 기사 수집).
  - *Why*: 사용자가 선택한 모드의 그래프 안에는 오직 그 종류의 기사들만 순수하게 모여 있어야 한다는 요구사항을 완벽히 충족합니다.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:

```
┌──────────────────────────────────────────────────────────────────────────┐
│                     Search Bar & 7-Mode Graph Switcher                   │
│  [뉴스 모드] [쇼핑 모드] [논문 모드] [특허 모드] [통계 모드] [지식 모드] [심층 모드] │
└──────┬──────────┬──────────┬──────────┬──────────┬──────────┬─────────┬──┘
       │          │          │          │          │          │         │
       ▼          ▼          ▼          ▼          ▼          ▼         ▼
┌──────────────────────────────────────────────────────────────────────────┐
│           Dedicated 3D Graph Store (Per-Mode Independent Spaces)         │
│  • Graph[뉴스]: 사안·이슈 기사 전용 군집 (X:반대↔찬성, Y:파급력, Z:신뢰도, C:논조) │
│  • Graph[쇼핑]: 제품 비교 기사 전용 군집 (X:저가↔고가, Y:품질·성능, Z:후기신뢰도) │
│  • Graph[논문]: 학술 근거 기사 전용 군집 (X:이론↔응용, Y:근거강도, Z:최신성, C:분야)│
│  • Graph[특허]: 선행 기술 기사 전용 군집 (X:기초↔응용, Y:권리범위, Z:최신성)     │
│  • Graph[통계]: 수치·공공데이터 전용 군집 (X:영향범위, Y:데이터신뢰도, Z:최신성)  │
│  • Graph[지식]: 개념·원리 해설 전용 군집 (X:쉬움↔전문적, Y:핵심도, Z:정확도)     │
│  • Graph[심층]: 복합 주제 심층 전용 군집 (X:AI결정, Y:AI결정, Z:신뢰도, C:하위질문)│
└────────────────────────────────────┬─────────────────────────────────────┘
                                     │ Switch Active Graph / Fetch Mode Data
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│                    VectorMap3D & Side Panels Renderer                    │
│  • Renders ONLY the active mode's 3D graph & its dedicated articles      │
│  • Displays the active mode's X/Y/Z axes & 4D Color Legend               │
└──────────────────────────────────────────────────────────────────────────┘
```

- **Data Model & State**:
  - `SearchModeId`: `'news' | 'shopping' | 'paper' | 'patent' | 'stats' | 'knowledge' | 'deep'`
  - `SEARCH_VISUALIZATION_MODES`: 사용자 정의 JSON 규격(`mode`, `purpose`, `axes: { x, y, z, color }`) 및 각 모드의 3D 축 극단 라벨, 색상 범례, 전용 검색 쿼리 접미사를 정의한 상수 배열.
  - `modeGraphs: Record<SearchModeId, DatasetItem>`: 각 모드별로 분리된 3D 그래프 데이터셋 스토어. 초기 로드 시 7개 모드 각각에 대해 해당 성격의 기사들만 모인 전용 기본 그래프가 준비되어 있으며, 새로운 키워드 검색 시에도 각 모드별로 전용 기사들을 구해 해당 모드의 그래프에 저장합니다.
- **Interactive Component & State Mapping**:
  - **모드 칩 버튼 클릭 (`handleSelectMode(modeId)`)**:
    1. `activeMode`를 `modeId`로 변경하고, 3D 뷰어의 활성 그래프를 `modeGraphs[modeId]`로 즉시 전환합니다.
    2. 3D 공간의 X·Y·Z 축과 색상 기준이 해당 모드 그래프의 축으로 바뀝니다.
    3. 현재 검색어(`currentQuery`)에 대해 해당 모드의 전용 기사가 아직 로드되지 않은 경우, 백엔드에 `(query, modeId)`를 요청하여 해당 모드 전용 기사들을 수집·분석해 그 모드의 그래프에 채웁니다.
    4. 랜딩 화면에서 모드 칩을 누르고 탐색을 시작하거나 3D 공간 상단에서 모드 칩을 누르면 즉시 해당 모드의 전용 3D 그래프로 이동하여 기사들을 보여줍니다.
